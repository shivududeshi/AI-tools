# Product: Spring PetClinic

Spring PetClinic is a sample web application demonstrating best practices for building Spring Boot applications. It models a veterinary clinic management system.

## Core Domain

- **Owners** — pet owners with contact details; can own multiple pets
- **Pets** — animals belonging to owners, with a type and birth date
- **Vets** — veterinarians with one or more specialties
- **Visits** — medical visit records linking a pet to a date and description

## Purpose

This is a reference/demo application used for learning and demonstrating the Spring ecosystem. It is not intended to be a production system, but the code quality, patterns, and conventions should be treated as production-grade.

## Access

The app runs at `http://localhost:8080` by default.
